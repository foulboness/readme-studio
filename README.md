# ୨୧ README STUDIO

> **a tiny studio for making your GitHub README feel like *you*.** ♡

README Studio is a cute little web tool for creating **personalized GitHub README sections** without having to stare at a blank `README.md` wondering where to start.

Pick a style, add your details, customize your sections, and copy your finished README straight into GitHub. ✦

---

## what is it?

**README STUDIO** is a front-end project designed to make GitHub profile customization easier, more creative, and a little more fun.

Instead of building everything from scratch, you can create things like:

* profile introductions
* about me sections
* tech stack lists
* project showcases
* currently learning sections
* status / mood cards
* social links
* GitHub stats sections
* custom quote blocks
* cute dividers & decorations

---

## tech stack

Built with simple web technologies:

**HTML** · **CSS** · **JavaScript**

---

## getting started

Clone the repository:

```bash
git clone https://github.com/foulboness/readme-studio.git
```

Open the project:

```bash
cd readme-studio
```

Then open:

```text
index.html
```

in your browser.

That's it!

---

## how it works

```text
choose a style
      ↓
add your information
      ↓
pick your sections
      ↓
customize everything
      ↓
preview your README
      ↓
copy the markdown
      ↓
paste it into GitHub ♡
```
